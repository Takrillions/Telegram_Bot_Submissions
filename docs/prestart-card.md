# Карточка до Start

Карточка является общей для всего экземпляра бота и не привязана к `channel_id`. Поэтому её изменение относится к глобальному профилю самого Telegram-бота, а не к оформлению конкретной предложки.

Доступ к редактированию глобальной карточки разрешён только `SUPERADMIN_TELEGRAM_ID`, заданному в production `.env`. `channels.owner_id` не даёт права менять эту карточку: владелец любой отдельной предложки остаётся только `CHANNEL_OWNER` своего `channel_id`. Если `SUPERADMIN_TELEGRAM_ID` отсутствует или некорректен, глобальное редактирование закрывается по принципу fail-closed, при этом остальные функции бота продолжают работать.

Текст применяется автоматически через Telegram Bot API `setMyDescription`. Перед применением SUPERADMIN видит предпросмотр; состояние дополнительно хранится в singleton-настройке БД для reset/audit.

Медиа выбирается в глобальном разделе `/panel`, валидируется, сохраняется и показывается в предпросмотре. После сохранения бот повторно выдаёт подготовленное фото/видео/анимацию и кнопку перехода в `@BotFather`, чтобы SUPERADMIN применил его через `Edit Bot → Edit Description Picture`.

Это ограничение платформы: актуальный HTTP Bot API умеет менять обычную profile photo (`setMyProfilePhoto`), но это другой элемент интерфейса и он не заменяет Description Picture центральной карточки. Для Description Picture используется `@BotFather → Edit Description Picture`.

Удаление и полный reset очищают локальный media-candidate и явно напоминают удалить уже применённое Description Picture через BotFather. Код не сообщает пользователю, что удалён удалённый Telegram-медиа-блок, поскольку Bot API не позволяет это проверить или выполнить.
