# Карточка до Start

Карточка является общей для всего экземпляра бота и не привязана к `channel_id`.

Текст применяется автоматически через Telegram Bot API `setMyDescription`. Перед применением владелец видит предпросмотр; состояние дополнительно хранится в singleton-настройке БД для reset/audit.

Медиа выбирается в `/panel`, валидируется, сохраняется и показывается в предпросмотре. После сохранения бот повторно выдаёт подготовленное фото/видео/анимацию и кнопку перехода в `@BotFather`, чтобы главный администратор применил его через `Edit Bot → Edit Description Picture`.

Это ограничение платформы: актуальный HTTP Bot API умеет менять обычную profile photo (`setMyProfilePhoto`), но это другой элемент интерфейса и он не заменяет Description Picture центральной карточки. Для Description Picture официальный Telegram по-прежнему указывает настройку через `@BotFather → Edit Description Picture`.

Удаление и полный reset очищают локальный media-candidate и явно напоминают удалить уже применённое Description Picture через BotFather. Код не сообщает пользователю, что удалён удалённый Telegram-медиа-блок, поскольку Bot API не позволяет это проверить или выполнить.
